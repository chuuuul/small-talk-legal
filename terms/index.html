서비스

오늘의 스몰토크는 매일 대화 주제와 대화 시작 문장을 제공하는 서비스입니다.

계정

이용자는 정확한 정보를 사용하고 자신의 로그인 정보를 안전하게 관리해야 합니다. 계정을 타인의 권리를 침해하거나 불법적인 목적으로 사용할 수 없습니다.

프리미엄 기능

프리미엄 기능은 서버에서 확인된 구독 권한과 앱에 표시된 이용 기간에 따라 제공됩니다. 현재 Android 비공개 테스트의 Test Store 구매는 실제 결제가 아니며, 실제 판매 조건은 공개 출시 전에 별도로 안내합니다.

콘텐츠

대화 주제는 정보 제공과 대화 보조 목적입니다. 중요한 의사결정의 전문적 조언으로 사용해서는 안 됩니다.

서비스 변경

안전, 정책 또는 운영상 필요한 경우 서비스를 변경하거나 중단할 수 있으며, 가능한 경우 앱 또는 공개 운영 채널을 통해 안내합니다.

계정 삭제

앱의 마이 화면 또는 외부 계정 삭제 페이지에서 계정을 삭제할 수 있습니다.
